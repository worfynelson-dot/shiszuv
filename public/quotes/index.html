API Docs

Free multilingual quotes API. Indonesia, Japan, English — 25 quotes each, always fresh.

3 Languages
75 Total Quotes
No Auth Required

Endpoints

GET 🇮🇩
/quotes/indonesia
Returns all 25 Indonesian motivational quotes
GET 🇯🇵
/quotes/japan
Returns all 25 Japanese proverbs & quotes with romaji
GET 🇬🇧
/quotes/english
Returns all 25 English quotes from world-renowned figures

Query Params

optional params 
?type=random   → Get 1 random quote from that language

Example:
/api/quotes/japan?type=random
